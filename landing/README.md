# ЗооВетМир — промо-страница

Отдельная статическая страница на дизайн-системе основного проекта.
С `ozvm.ru` и `api.ozvm.ru` никак не связана и ничего в них не меняет.

## Структура блоков

1. **Шапка** — логотип, меню, контакты, соцсети. Липкая, на мобильном сворачивается в бургер.
2. **Слайдер баннеров** — 3 баннера: автопрокрутка, стрелки, точки, свайп, стрелки клавиатуры.
   Пауза при наведении. Под слайдером — полоса из четырёх преимуществ.
3. **Категории** — 6 карточек по видам животных, с затемнением и зумом фото при наведении.
4. **Товары** — витрина из 6 карточек с ценой, старой ценой, бейджами и наличием.
   Переходов нет: блок презентационный, как и просили.
5. **Почему мы** — 4 преимущества плюс полоса с цифрами.
6. **Как заказать** — 4 шага с нумерацией.
7. **Отзывы** — 3 карточки с оценкой и автором.
8. **Контакты** — призыв к действию, телефон, почта, город. Ниже футер.

## Анимация лапок

Перенесена из `ozvm.ru/src/components/UI kit/paws1…paws5` — те же пять лапок
с исходными размерами (120/180/300px), позициями (13/17/55/52/70vw),
задержками старта (0/0.3/1.3/1.6с) и прозрачностью (0.2–0.4).

В оригинале шаг задавался таймером в React: каждые 2 секунды элементу
присваивался `translateY(-N vh)`, 10 шагов по кругу, а мигание шло отдельной
CSS-анимацией на 2.5с. Здесь то же самое сделано целиком на CSS:
внешний элемент шагает (`steps(1)` даёт такие же мгновенные скачки),
внутренняя картинка мигает. Периоды 20с и 2.5с не кратны — как и в оригинале,
поэтому лапки не выглядят синхронными. JS для этого не нужен.

Лапки живут в первом экране, поверх фирменного фона `pawsBCG.svg`.

## Что улучшено точечно

Дизайн не менялся — цвета, шрифт Jost и характер оформления те же. Правки:

- шкала кеглей и отступов на `clamp()` — плавно тянется без скачков на брейкпоинтах;
- у карточек появилась тонкая обводка `--color-line` вместо «висящей» тени,
  тень включается только при наведении;
- видимый фокус с клавиатуры (`:focus-visible`) — в основном проекте его не было;
- поддержка `prefers-reduced-motion`: при системной настройке «меньше движения»
  лапки и появление секций замирают;
- у изображений `loading="lazy"`, у декоративных — пустой `alt`.

## Запуск

Обычная статика, сборка не нужна. На Vercel: **Framework Preset — Other**,
Build Command пустой, Output Directory — корень папки.

Локально подойдёт любой статический сервер, например `npx serve .`
(просто открыть `index.html` из файловой системы не выйдет — браузер
заблокирует загрузку `css/` и `js/` по протоколу `file://`).

## Структура файлов

```
index.html          вся страница
css/tokens.css      цвета, шрифт, радиусы, шкала отступов

js/landing.js       слайдер, бургер-меню, появление секций
img/                логотип, лапки, фон, фотографии
```
