# ЗооВетМир — розничная часть

Отдельный статический сайт: лендинг компании, витрина акций и админка к ним.
Живёт на своём поддомене и разворачивается независимо от основного проекта.

Основной проект не трогает: `ozvm.ru` (Next.js, оптовый магазин) и
`api.ozvm.ru` (Laravel) остаются как есть, общего кода нет.

Разворот и план запуска — [DEPLOY.md](DEPLOY.md).

## Страницы

| Файл | Адрес на поддомене | Что это |
|---|---|---|
| `landing/index.html` | `/` | Лендинг компании |
| `index.html` | `/index.html` | Витрина акций |
| `promotion.html` | `/promotion.html?id=N` | Страница одной акции |
| `admin.html` | `/admin.html` | Админка: акции и контент лендинга |
| `design-system.html` | `/design-system.html` | Стайлгайд: цвета, шрифт, кнопки |

## Структура

```
config.js, api.js      общие настройки и обёртка над API основного проекта
css/, js/, img/        витрина акций, админка, стайлгайд
landing/               лендинг — свои css, js и картинки
deploy/                конфиг nginx, Dockerfile, compose
```

## Где хранятся данные

В `localStorage` браузера. У каждого посетителя своя копия: клиент может
добавлять и менять акции, не мешая другим.

- акции — `js/store.js`, объект `PromoStore`
- контент лендинга — `js/landing-store.js`, объект `LandingStore`

Вернуть исходные данные: `PromoStore.resetToSeed()` из консоли браузера,
у лендинга — кнопка возврата к исходному виду в самой админке.

Чтобы сбросить сохранённое у всех, кто уже открывал страницу, поднимается
`SEED_VERSION` в `js/store.js` или `VERSION` в `js/landing-store.js`.

## Доступ в админку

Логин и пароль заданы в [`js/auth.js`](js/auth.js).

> **Это не настоящая защита.** Сайт статический, проверка логина идёт
> в браузере, пароль виден в исходниках страницы. На поддомене админка
> обязательно закрывается basic auth на nginx — см. DEPLOY.md.

## Изображения акций

При загрузке файла открывается редактор кадрирования
([`js/cropper.js`](js/cropper.js)): картинку можно двигать мышью и менять
масштаб. Кнопка **«Кадрировать»** позволяет переснять кадр у уже выбранного
изображения, в том числе у готового из галереи.

На выходе JPEG 1200×675 (16:9) — ровно то соотношение, в котором картинка
показывается и в плитке на витрине, и обложкой на странице акции. Поэтому
выбранный кадр совпадает с тем, что увидит покупатель.

Заодно решается вопрос веса: результат весит ~120 КБ, тогда как исходное фото
с телефона на 3–5 МБ в base64 переполнило бы `localStorage` (лимит ~5 МБ).

## Даты

Вводятся вручную в формате ДД.ММ.ГГГГ, точки подставляются сами. Штатный
`<input type="date">` не используется: всплывающий календарь рисует браузер
и берёт язык из своего интерфейса, а не из `lang="ru"` страницы — у пользователя
с английским браузером месяцы выводились по-английски. Внутри даты хранятся
в ISO (ГГГГ-ММ-ДД).

## Локальный запуск

Любой статический сервер:

```bash
npx serve .
```

Открыть `index.html` двойным кликом не получится — браузер заблокирует
загрузку `js/` и `css/` по протоколу `file://`.

Локально корнем будет витрина акций: подмена корня на лендинг живёт
в конфиге nginx. Лендинг открывается по `/landing/`.
