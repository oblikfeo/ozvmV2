# Акции — демо для клиента

Отдельное статическое приложение: витрина акций + админка для их заполнения.
Никак не связано с основным проектом (`ozvm.ru`, `api.ozvm.ru`) и ничего в нём не меняет.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Витрина акций — крупные плитки |
| `promotion.html?id=N` | Страница одной акции |
| `admin.html` | Админка: добавление и редактирование акций |
| `design-system.html` | Витрина стилей: цвета, шрифт, кнопки |

## Доступ в админку

```
логин:  admin
пароль: zoovetmir2026
```

Задаются в [`js/auth.js`](js/auth.js).

> **Это не настоящая защита.** Приложение полностью статическое, проверка логина
> происходит в браузере, и пароль виден в исходном коде страницы. Такой вход нужен
> только чтобы показать клиенту сценарий «админ заходит под своим логином».
> В боевой версии авторизация должна идти через Laravel.

## Где хранятся данные

Сейчас — в `localStorage` браузера. У каждого посетителя своя копия: клиент может
добавлять, менять и удалять акции, не мешая другим и ничего не ломая.
Кнопка **«Сбросить к демо-данным»** в админке возвращает исходные 6 акций.

Загруженные картинки сжимаются в браузере до 1200px и хранятся там же как data URL
(у `localStorage` лимит ~5 МБ, поэтому без сжатия пара фото с телефона его переполнили бы).

Демо-акции и встроенные изображения лежат в [`js/store.js`](js/store.js).
Чтобы обновить демо-данные у всех, кто уже открывал страницу, нужно поднять
`SEED_VERSION` в этом файле.

## Что меняется при переносе в основной проект

Вся работа с данными изолирована в `js/store.js` — страницы дёргают только
`PromoStore.getAll / getActive / getById / upsert / remove`. При интеграции этот файл
заменяется на вызовы API, вёрстка не трогается.

На стороне Laravel понадобится:

- таблица `promotions`: `title`, `slug`, `short_description`, `full_description`,
  `image_path`, `date_start`, `date_end`, `active`, `sort`
- загрузка картинки файлом в `storage/app/public/promotions/`, **в БД пишется путь**, не сам файл
- роуты в стиле существующего `routes/api.php`:
  - `GET /api/v1/promotions`, `GET /api/v1/promotions/{slug}` — публичные (`option_auth`)
  - `POST/PUT/DELETE` — под `auth:sanctum` + проверка прав администратора

## Деплой на Vercel

Обычная статика, сборка не нужна.

1. Залить эту папку в репозиторий
2. В Vercel: **Add New → Project**, выбрать репозиторий
3. Framework Preset — **Other**, Build Command оставить пустым,
   Output Directory — корень проекта (или `promo-prototype`, если папка лежит внутри репозитория)

На корневом URL откроется витрина акций, админка — по адресу `/admin.html`.

## Локальный запуск

Любой статический сервер, например:

```bash
npx serve .
```

Просто открыть `index.html` двойным кликом не получится — браузер заблокирует
загрузку `js/` и `css/` по протоколу `file://`.
